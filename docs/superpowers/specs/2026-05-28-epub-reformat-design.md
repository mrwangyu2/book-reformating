# EPUB 图片跨页拆分排版工具 — 设计文档

## 概述

一个 Python CLI 工具，批量处理目录中的 EPUB 文件：将跨页图片从中间切开，旋转 90° 后等比放大填满原尺寸，输出适合横向阅读的 EPUB。

## 处理流程

1. 扫描输入目录中的所有 `.epub` 文件（非递归）
2. 逐个打开 EPUB，提取元数据（书名、作者）和所有图片
3. 每张图片执行：垂直中线切开 → 顺时针旋转 90° → 等比放大填满原图尺寸
4. 用处理后的图片（一张变两张）重建 EPUB，保留原元数据
5. 写入输出目录，文件名与输入相同

## 模块架构

```
cli.py               argparse 参数解析，遍历文件，协调流程
epub_processor.py    ebooklib 读写 EPUB，提取元数据，重建 EPUB
image_processor.py   Pillow 图片处理：切分、旋转、等比填充
```

### 依赖

- **ebooklib** — EPUB 解析与生成
- **Pillow** — 图片处理
- **argparse** — 标准库，CLI 参数解析。无额外 CLI 框架依赖

## CLI 接口

```
epub-reformat --input-dir <目录> --output-dir <目录> [选项]
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-i` / `--input-dir` | 输入目录，扫描其中 .epub 文件 | 必填 |
| `-o` / `--output-dir` | 输出目录，处理后 EPUB 写入此处 | 必填 |
| `-q` / `--quality` | JPEG 输出质量 (1-100) | 95 |
| `-v` / `--verbose` | 输出详细处理日志 | False |

行为：输出目录自动创建；同名文件覆盖；退出码 0 = 全部成功，非 0 = 有失败项。

## 图片处理算法

**输入：** W × H 跨页图片

1. **垂直中线切开**：左半 `W/2 × H`，右半 `W/2 × H`。W 为奇数时左半多 1px
2. **顺时针旋转 90°**：左半 → `H × W/2`，右半 → `H × W/2`
3. **等比放大填满 W×H**：
   - `scale = max(W / H, H / (W / 2))`
   - 按 scale 等比缩放
   - 从中心裁切出 `W × H` 区域

**输出：** 左半 → 第 1 页，右半 → 第 2 页，spine 中连续排列。每页 W×H，适合横向阅读。

## 错误处理

逐层容错，单点失败不中断整体：

| 场景 | 行为 |
|------|------|
| 输入目录不存在 | 报错退出 |
| 输入目录无 .epub | 提示并正常退出 |
| 损坏的 EPUB | 警告，跳过，继续 |
| EPUB 无图片 | 警告，跳过 |
| 图片损坏/不支持格式 | 保留原图不处理，警告 |
| 图片极小 (<10px) | 跳过处理，保留原图 |
| 输出目录无写权限 | 报错退出 |
